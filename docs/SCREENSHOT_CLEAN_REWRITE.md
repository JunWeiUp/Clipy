# macOS 截图与录屏：独立重写验收清单

## 目的与边界

本文只定义用户可见的行为、可检查的产物和发布前验证，不规定源码结构、算法、界面内部实现或第三方代码的移植方式。功能范围取自 [中文 README](../README_ZH.md#-截图与标注macos)、[英文 README](../README.md#-screenshot--annotation-macos)、[macOS 设计规范](MACOS_DESIGN.md)、应用菜单、截图设置的可见选项，以及 [开发验证说明](DEVELOPMENT.md)。若文档与新界面的入口名称不同，以“用户能够发现并完成相同任务”为验收原则。

验收使用虚构文字、测试二维码和测试画面，不使用用户真实剪贴板、密码、通知或私人影像。所有截图、录屏和系统权限均由测试者主动触发。表中“通过”指实际安装的应用完成操作，且最终文件或剪贴板内容经过独立查看；界面出现成功提示本身不算通过。

**准入要求：** P0 项目全部通过；P1 项目在计划发布的 macOS 版本上通过或明确记录该系统不支持的原因；下面的手工矩阵和非功能门槛留下设备、系统、应用构建号、步骤、产物及结果。任何崩溃、无法退出的会话、敏感内容外泄、静默丢失产物均阻断验收。

| CAP-03 | P0 | 首次缺少屏幕录制权限时，给出明确提示和系统设置入口；授权后无需清除用户数据即可继续。拒绝授权、从系统设置撤销授权时不产生空白或误导性的“成功”产物。 |

### 滚动长截图

| ID | 级别 | 场景与通过标准 |
|---|---|---|
| SCR-01 | P0 | 从选区进入滚动长截图后，侧边实时预览随新增内容增长；停止后交付一张可打开的长图，图像高度超过初始选区，最后新增的内容在成品中可见。 |
| SCR-02 | P0 | 对同一测试页分别缓慢、快速滚动以及短暂停顿，拼接结果没有肉眼可见的重复段、缺口、错位或不合理拉伸；无法可靠拼接时提供明确反馈，避免交付看似成功的错误长图。 |
| SCR-03 | P1 | 手动滚动与自动滚动均可用；自动速度 1–5 档改变滚动节奏。启用固定页眉检测时，固定页眉不在长图中反复出现。 |

### 18 个标注工具

以下逐项检查：能从主／二级工具栏发现，操作后画布有可见结果，导出文件保留结果；选中、移动或调整可编辑标注时命中区域正确；撤销／重做不破坏其他标注。颜色、粗细、字体等选项只需在相应工具上检查。标注可以跨越不同亮度和颜色的测试背景，仍应辨认。

| ID | 工具 | 最小验收场景 |
|---|---|---|
| ANN-01 | 画笔 | 连续笔画、不同粗细；平滑模式“无／平滑／精细”可区分，设备支持时压感开关有效。 |
| ANN-02 | 直线 | 两端点位置和线宽、颜色正确；水平、垂直、斜向均可绘制。 |
| ANN-03 | 箭头 | 六种样式均可选择并在导出图中区分，至少覆盖直线、弯曲、虚线、手绘效果；方向与端点正确。 |
| ANN-04 | 矩形 | 空心矩形边框位置、颜色、线宽正确。 |
| ANN-05 | 填充矩形 | 内部填色与边界符合所选颜色及透明度。 |
| ANN-06 | 椭圆 | 椭圆大小、位置、边框或填充选项正确。 |
| ANN-07 | 荧光笔 | 拖过黑字和多色背景后文字仍可辨认，正片叠底效果体现在导出图中；智能适配文字行高开关生效。 |
| ANN-08 | 富文本 | 粗体、斜体、描边、背景及字体设置可见；中英混排、换行、重新编辑后导出无裁字。 |
| ANN-09 | 编号 | 连续放置的编号按序递增；移动或撤销一个编号不造成肉眼可见的重复、跳号或错位。 |
| ANN-10 | 图章 | emoji 和图片图章均可放置，缩放、移动后导出清晰且位置正确。 |
| ANN-11 | 马赛克 | 指定区域被像素化，区域外不变；小、中、大笔刷等可见选项生效。 |
| ANN-12 | 模糊 | 指定区域模糊，边界和强度符合所选选项，导出无原图闪现。 |
| ANN-13 | 纯色遮挡 | 敏感测试文字在导出图中完全被指定纯色覆盖，复制或另存结果一致。 |
| ANN-14 | 擦除遮挡 | 对遮挡区域执行擦除后，可见结果仅影响预期范围；撤销能恢复上一步。 |
| ANN-15 | 放大镜 | 放大指定局部，放大内容与原位置对应，尺寸和位置可调。 |
| ANN-16 | 像素标尺 | 两端点及显示的像素距离随拖动变化，1×／Retina 场景的度量定义一致。 |
| ANN-17 | 取色器 | 在预设纯色测试块上取得正确颜色，并可将该颜色用于后续标注。 |
| ANN-18 | 聚光灯 | 指定区域突出、其余区域弱化，导出与预览一致。 |

|---|---|---|---|

## 非功能验收指标

以下是独立重写的**建议发布门槛**，不是当前实现表现。测试前固定一台基准 Apple Silicon Mac，记录硬件、屏幕、系统版本和后台负载；超过门槛时附测量数据讨论调整，不以主观“感觉流畅”替代。

| 指标 | 建议门槛与测量方式 |
|---|---|
| 可用性 | M01–M12 中全部 P0 场景完成；连续 20 轮常见操作零崩溃、零无法关闭的浮层、零损坏产物。Esc 可取消当前操作或按编辑器保存提示关闭；键盘和鼠标均能到达主要操作。 |
| 响应 | 基准机已授权、预热后连续 20 次快捷键呼出选区，95% 在 2 秒内出现可交互界面；第一次冷启动单独记录。普通 4K 静态截图确认至可复制／打开产物，95% 在 3 秒内完成。 |
| 图像正确性 | 静态截图尺寸与选区在选定的 1×／原生像素规则下相符，容差不超过 1 设备像素；不混入截图工具界面。标注、特效和遮挡在预览、剪贴板、保存文件之间一致。 |
| 长图正确性 | M04–M05 的每种有效滚动样本至少 3 次成功；预览在新增稳定内容后继续增长，成品无明显重叠、缺口或错位。失败时不得自动交付误导性成品。 |
| 音视频正确性 | 5 分钟 1080p／30 FPS 测试录屏可从头到尾播放；抽样核对起、中、末的画音，音画偏差不超过 250 ms；音频轨、摄像头及鼠标／按键叠层与开关一致。GIF 可在系统预览中播放。 |
| 内存与空闲资源 | M11 后关闭所有截图、录屏、编辑和贴图窗口，空闲 5 分钟的进程物理占用相对操作前基线增加不超过 100 MiB，后 5 轮不持续单调攀升；截图功能关闭后无持续录制指示或截图专属高 CPU 活动。记录测量工具与采样值。 |
| 权限与隐私 | 未授权时不绕过系统提示；取消操作不保存原始屏幕内容；OCR／二维码结果仅由明确操作展示。自动遮挡的测试字段在交付图中不可读。测试证据只用虚构数据。 |
| 兼容与本地化 | 最低 macOS 13 可完成基础截图和录屏；较新系统专属能力在不支持时可解释且不阻断基础功能。简体中文和英文界面没有未翻译键值、截断的主操作、相反的设置语义。 |
| 持久性与恢复 | 快捷键、默认模式、保存目录、输出格式、录制和工具偏好在正常重启后保留；权限变化、保存失败、设备断开后再次操作仍可用。输出文件能由独立系统应用打开。 |

## 已确定的交互与当前验证范围

- GIF 由录制完成后的媒体窗口显式导出；录制取消会删除临时文件。
- 二维码结果在识别窗口逐条显示并可复制；没有结果时明确显示空状态。
- 自动遮挡只建议识别到的凭据、支付卡号、电子邮箱和电话号码。用户可在预览中逐条选择，确认后才把遮挡烧录到新图；未命中时仍可手工遮盖。
- 窗口捕获以选定时的窗口 ID 获取目标，不再按确认时的前台窗口猜测。跨显示器窗口及显示器切换需按 M02 真机验收。
- Apple 系统翻译只在 macOS 15+ 可用，并由识别结果窗口中的按钮再次由用户主动触发；macOS 13/14 显示原因。
