# Internet relay

The former Python relay has been retired and its implementation removed.
Current clients use the independently maintained Common Relay service and SDK.

See [Common Relay integration](COMMON-RELAY-SDK.md) for dependency versions,
identity boundaries and invitation behavior. Service deployment is documented
[upstream](https://github.com/JunWeiUp/common-relay/blob/v0.1.0/docs/DEPLOYMENT.md).
Old shared-key deployment commands do not apply to current clients. Historical
implementation details remain available in Git history.
