# 原生控制面板验收记录

用户选定第一张方案并确认交互原型后，已接入正式 Swift/AppKit 应用。网页原型仅保留为设计资料，正式界面不加载网页。

## 实现

- 左键状态栏图标打开非激活浮层；右键保留原生菜单。固定、外部点击关闭、Escape 分层返回及 ⌘F / ⌘1–6 导航已接入。
- 顶部搜索与隐藏图标常驻；剪贴板、片段、工具切换中部内容，底部连接截图、查词、智能切换、设备和通知。
- 使用真实历史检索、片段、设备、通知及原有功能窗口；完整历史窗口接收当前查询。区域截图的选区工具栏继续提供长截图与录屏。
- 复制按钮仅复制；历史行沿用文本类型自动粘贴，延后粘贴前检查调用应用、剪贴板版本、窗口状态及当前会话。关闭与重新打开取消迟到查询和旧动作。
- 辅助功能状态、未知或不可操作图标保持明确反馈。AX 未确认结果不重试，也不弹模态窗口覆盖可能已经打开的原应用菜单。

## 验证

- 固定签名构建通过；安装前后 Bundle ID、证书链、TeamIdentifier 和 designated requirement 一致，签名验证通过。
- `scripts/test_macos_core.sh` 全部通过，包括新面板的屏幕边界、逻辑坐标、键盘选择、搜索竞态、关闭重开、粘贴前置检查，以及既有历史、隐藏图标、智能切换、同步等回归。
- `bash scripts/check.sh repo`、`git diff --check` 通过。
- 此目录截图由原生 `MenuBarPanelView` 使用虚构数据渲染，覆盖中文浅色/深色、工具页及英文；没有用户真实历史或通知。图中顶部仍是调整前的 Logo 与独立搜索行；当前源码和 README 截图已改为单行搜索。可用 `CLIPY_PANEL_SNAPSHOT_DIR` 运行核心脚本重新生成。
- 已完成本机安装和实际进程路径核对。桌面验证工具未建立可用窗口，后续查询因当前工具凭据没有活动回合权限被拒绝，因此未宣称完成安装版的鼠标全流程、真实粘贴或原应用菜单操作验收。
- macOS 13 部署目标编译通过；其他系统版本未完成实机验收。此处记录的是当次验收状态，源码提交与公开发布状态以 Git 和 Release 页面为准。
