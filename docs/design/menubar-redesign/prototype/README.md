# Clipy 轻量控制面板 · UI 原型

用户选定第一张概念图后制作的独立 React/Vite 原型。用于确认布局与操作层级；不包含 macOS 系统调用，不读取真实剪贴板、通知或设备，不安装或替换应用。

## 本地查看

在此目录执行 `npm ci`，再运行 `npm run dev -- --host 127.0.0.1 --port 4173 --strictPort`。当前评审地址为 `http://127.0.0.1:4173/`。`npm run build` 可验证前端构建。

## 可体验的流程

- 首屏六条历史，文字/图片/文件筛选，搜索历史、片段与工具，查看全部历史；点击复制展示模拟反馈。
- 片段按工作/个人分类；工具包含截图录屏、查词、单词本、智能切换和密码生成。
- 隐藏图标常驻，可打开原应用菜单的交互示意；外侧评审控制可切换无图标、缺权限、外屏暂停和空内容。
- 设备页模拟发送文件、手动添加设备、开关同步；通知页查看详情与标为已读。
- 齿轮进入设置，固定按钮切换点击外部是否关闭；菜单栏图标可重新打开。
- 搜索框支持上下键、回车；⌘F 聚焦搜索；⌘1–6 使用历史；Esc 依次关闭弹窗、更多菜单、搜索、子页面与面板。中文组词期间不处理这些按键。
- 浅色、深色及窄窗口；弹窗焦点约束，图标按钮有无障碍名称，减少动态效果适配。

## 评审与边界

主要功能入口已连通。截图、系统授权、片段编辑等独立原生窗口仅展示交接说明；原应用菜单、文件发送、查词和密码均为模拟内容。没有网络词典或同步后端，不生成可用于账户的密码，不触发真实复制/粘贴。

原型切换视图在同一个固定高度面板内完成，图标栏、搜索与底部操作保持可见；内容过多时仅中部滚动。原生实机验收记录见 `../native/README.md`；网页验证不能替代前台应用焦点、粘贴目标、权限与原菜单交接的检查。

设计对照见 `public/qa/compare.html`，检查结果见 [design-qa.md](design-qa.md)。原生应用现已按评审结果实现；本目录仍是隔离的设计原型，不代表当前原生界面。原生顶部已改为搜索与置顶／设置同一行，见 `../../../../clipy_macos/Sources/MenuBarPanel/` 和 `../../../MACOS_DESIGN.md`。

## 素材

- 图标组件：`@phosphor-icons/react`，使用统一 regular 线条；正式原生版本采用 SF Symbols。
- 三个应用图标：对应已安装应用的公开 AppIcon 素材，仅作产品交互示例，商标属于原权利人。
- 外侧背景：沿用仓库 `res/screenshots/gallery-background.png`；外侧标题、主题/状态控件仅属于评审页面，不进入正式面板。
- 湖泊缩略图：内置 ImageGen 生成，提示词为自然光下山峰、森林与湖面倒影的 3:2 风景照片，不含文字或 UI。
- 首屏设计参考：上级目录 `compact-panel.png`。`public/qa` 为视觉对照证据，不参与产品 UI。
