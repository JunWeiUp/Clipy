# macOS 入口改版 · 设计记录

用户已选择第一张「轻量控制面板」。已制作独立交互原型，见 [prototype/README.md](prototype/README.md)。用户已确认原型并授权实施；原生实现位于 `Sources/MenuBarPanel/`，仍未公开发布。

## 目标

从菜单栏图标打开一个层级清晰的轻量入口，允许使用浮层或可固定窗口。剪贴板仍是核心任务，隐藏的菜单栏图标在首屏直接展示；完整工具与设备功能可到达，但不全部堆在首屏。

## 三个探索方向

- 轻量控制面板：约 510 × 700 pt。顶部搜索与隐藏图标横排，中部剪贴板/片段/工具切换，下方少量快捷动作和设备、通知入口。
- 双栏工作台：约 800 × 650 pt。可固定窗口，左侧导航、右侧内容与预览；隐藏图标在顶部常驻，适合连续整理和操作。
- 快捷启动面板：约 640 × 560 pt。搜索与键盘优先，左侧窄功能栏，中间最近内容；底部常驻隐藏图标栏，适合快速唤起即用即走。

## 功能归属

| 功能 | 设计位置 |
| --- | --- |
| 最近复制、全文历史搜索、类型筛选 | 默认内容区；完整管理打开历史窗口 |
| 常用片段、文件夹 | 独立标签或导航项；编辑进入现有片段窗口 |
| 隐藏菜单栏图标 | 常驻横排，不使用子菜单；溢出可横向滚动 |
| 区域/窗口/全屏/滚动截图、录屏 | 截图快捷入口及其二级选项 |
| 查词、单词本、智能切换、生成密码 | 工具页；查词与智能切换可设为快捷入口 |
| 局域网设备、发送文件 | 设备页；连接状态在底部摘要 |
| 通知同步 | 独立通知入口与未读计数 |
| 偏好设置、权限、日志 | 设置；日志仍在关于与诊断 |
| 退出 | 更多菜单 |

## 交互约束

- 点击剪贴板条目沿用复制/粘贴的现有偏好，鼠标悬停显示次要操作，避免每行铺满按钮。
- 点击隐藏图标前关闭浮层，再尝试原应用菜单动作；不可操作时明确提示，不以启动应用替代。
- 隐藏图标为空时缩为一行状态；缺权限时就地提供设置入口，不展示多行诊断信息。
- 搜索支持中文输入法；上下键导航、回车执行、Escape 关闭。固定窗口与临时浮层的关闭规则应明确区分。
- 普通内容使用不透明语义背景，材质限标题/导航区域；支持浅深色及减少动态效果。
- 演示内容、图标数量与通知数量均为虚构，不代表当前设备检测结果。

## 实施状态

第一方案的剪贴板、片段、工具、设备、通知、设置、空状态及权限状态已在原型中补齐。原生实现现位于 `clipy_macos/Sources/MenuBarPanel/`，采用 560 × 716 pt 首选尺寸并按屏幕可用区域收缩。原生顶部已改为搜索与置顶／设置同一行；当前实现以 `docs/MACOS_DESIGN.md` 为准。公开发布与源码提交是不同步骤。
