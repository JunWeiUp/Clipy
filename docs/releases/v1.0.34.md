# Clipy v1.0.34

## 中文

- **Windows 窗口与托盘**：统一大窗口、剪贴板快速面板、截图结果的切换；托盘单击即可打开/收起面板，支持 ×、Esc 和明确的主窗口入口，关闭窗口保持后台同步，只有“退出”结束程序。修复单击被重复处理、设置页出现在无边框小窗等问题。
- **Windows 截图**：修复启动生命周期导致截图无响应的问题，预生成暗色背景，避免全屏透明绘制长时间阻塞；区域、窗口、屏幕截图及结果回传有原生和客户端回归覆盖。
- **界面更新**：Windows 使用 Fluent 风格布局与控件；macOS 历史、片段、设备和通知合并为主窗口，更新设置、查词、标注与录屏相关界面；Android/iOS 更新平台外观和可访问性布局。
- **macOS 模型翻译**：增加独立的模型翻译配置、模型列表获取/筛选及受限的回环 HTTP 支持，保留本地钥匙串凭据存储。
- **工程与依赖**：共享 Flutter 工程移动到 `clipy_flutter/`，安装身份、数据库和偏好键保持兼容；Common Relay 改为锁定的官方包依赖，清理旧服务和重复副本。原生 Android 工程仍为未发布的备选实现。
- **实验性手机控制 Mac 屏幕**：默认关闭，需要在 Mac 上主动配置。启用后所有连接的同步设备可发起控制，局域网连接本身不验证设备身份；仅适用于可信网络与设备。真实锁屏解锁的完整验收尚未完成，请先阅读[能力边界与配置](../SCREEN_CONTROL.md)，不要视为生产就绪功能。

提供 macOS Apple Silicon ZIP、Android arm64 APK 和 Windows x64 ZIP。iOS 仍需自行签名构建，不提供公开安装包。macOS 包采用临时签名、未公证，Windows ZIP 未签名；Android 保持原有发布签名。更新前保留数据，Android 覆盖安装必须使用相同签名与更高构建号。

## English

- **Windows windows and tray:** consistent transitions between the main window, clipboard quick panel and capture results. A single tray click toggles the panel; ×, Esc and explicit main-window actions are available. Closing hides the app; only Exit quits. Fixes duplicate click handling and full pages appearing inside a small frameless panel.
- **Windows capture:** fixes the startup lifecycle guard that blocked screenshots and replaces expensive full-screen alpha painting with a pre-dimmed bitmap. Native and client regressions cover capture, cancellation and result delivery.
- **Platform UI:** Fluent-style Windows controls; a unified macOS window for history, snippets, devices and notifications; updated preferences, vocabulary and capture/editor surfaces; platform presentation and accessibility layout improvements on Android/iOS.
- **macOS model translation:** separate model configuration, model discovery/filtering and constrained loopback HTTP support, with credentials retained in local Keychain storage.
- **Repository and dependencies:** shared Flutter sources move to `clipy_flutter/` while installed identities, database formats and preference keys remain compatible. Common Relay uses pinned official packages; retired server code and duplicate snapshots are removed. Native Android remains an unpublished alternative.
- **Experimental phone screen control:** disabled by default and explicitly configured on the Mac. Once enabled, all connected sync peers can request control; LAN connectivity does not authenticate peer identity. Use only with trusted networks and devices. Complete real locked-screen unlock acceptance is still pending; see the [scope and setup](../SCREEN_CONTROL.md).

Assets: macOS Apple Silicon ZIP, Android arm64 APK and Windows x64 ZIP. iOS requires a separately signed source build. macOS is ad-hoc signed and not notarized; Windows ZIPs are unsigned. Android retains the existing release signer. Preserve application data and use the same Android signer with a higher build number for in-place upgrades.
