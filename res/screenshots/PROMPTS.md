# Gallery generation prompts

Generated using the built-in imagegen tool. The first reference is `gallery-background.png`; the second is the corresponding original `macos-*-en.png` capture. Outputs are the `macos-*-showcase.png` presentation images. Original captures remain available separately for exact UI reference.

## Background

Use case: ads-marketing. Asset type: decorative background for a GitHub README gallery presenting real macOS productivity app screenshots. Create one 1536x1024 landscape background with a quiet warm ivory center covering 80% of the image, subtle pale sky blue gradient glow in upper right and soft sage glow lower left. At the far edges only, tiny refined 3D paper sculpture accents: a folded paper ribbon bottom right and two softly rounded floating ivory paper cards upper left. Minimal premium editorial style, soft natural studio shadows, calm airy matte materials. No text, no letters, no icons, no logos, no interface, no mockup screens, no borders. Main center and upper center must remain very clean to allow a separate real screenshot to be laid over this background. Accent objects mostly clipped by outer corners. This background will be reused consistently across four app screenshot presentation cards.

## menu

Use case: compositing. Create a polished GitHub README screenshot presentation card in landscape 1536x1024. Input image 1 is the decorative background; input image 2 is the actual Clipy menu bar English screenshot, the edit target that must be inserted intact. Use the background across the full card. Place the tall menu screenshot on the RIGHT, front-facing, preserving original aspect ratio, about 85% of canvas height, subtle soft realistic shadow. Preserve ALL original screenshot text, keyboard symbols, icons, controls, separator positions, selection blue and content as faithfully as possible; no redesign, no invented entries, no omissions, no crop, no perspective. Left side add heading 'Always within reach.' in elegant charcoal sans serif about 64px, three balanced lines. Small label above 'CLIPY FOR MACOS'. Below the heading, smaller body text 'Your clipboard, snippets, and everyday tools. One quiet place in the menu bar.' No additional icons. Original screenshot gray material can be harmonized into a light warm translucent frosted surface with same text contrast; all UI details stay. Keep paper illustrations at far corners only. Use this same pale ivory, blue and sage palette as a four-image gallery, premium editorial and calm. This is a showcase frame around a real product screenshot, not a new interface design.

## snippets

Use case: compositing. Create a polished GitHub README screenshot presentation card in landscape 1536x1024. Input image 1 is the decorative background; input image 2 is the real Clipy Snippet Library English screenshot, the edit target that must be inserted intact. Use the background across the full card. Center the screenshot prominently with generous 90px outer margins, preserved original aspect ratio, subtle soft realistic shadow, a fine edge, and no perspective or rotation. Preserve ALL original screenshot pixels, typography, controls, words, content and selection colors as faithfully as possible; do not redesign, omit, invent, translate or reflow the UI. Do not add a fake window title bar. Add only a small tasteful heading "Snippet Library" outside and above the screenshot in dark charcoal clean sans serif. The screenshot must occupy most of the canvas and remain fully visible with no crop. Paper illustrations stay at the extreme background corners behind the screenshot, calm and understated. No other added text, watermark, icon or label. The same ivory, very pale blue and sage paper background and flat front-facing screenshot layout will be used for four matching gallery images.
