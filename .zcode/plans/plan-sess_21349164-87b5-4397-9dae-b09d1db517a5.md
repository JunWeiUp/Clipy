## 去掉滚动截图（长截图）功能

彻底移除 macOS 端的滚动截图/长截图功能，保留区域/窗口/全屏截图与标注等其他功能不受影响。Android 端无此功能，无需改动。

### 1. 删除 4 个滚动截图专属文件
- `clipy_macos/Sources/ScrollingImageStitcher.swift`
- `clipy_macos/Sources/ScrollingCaptureSession.swift`
- `clipy_macos/Sources/ScrollingCaptureOverviewPanel.swift`
- `clipy_macos/Sources/ScrollingCaptureStream.swift`

### 2. 构建脚本
- `build_macos_app.sh`：从 `SWIFT_SOURCES` 数组中删除上述 4 行。

### 3. 类型与协议清理（用编译器驱动后续修改）
- `ScreenshotTypes.swift`：删除 `ScreenshotCaptureMode.scrolling`（line 9）。
- `CaptureOverlayWindow.swift`：
  - 删除 `CaptureOverlayRequest.scrollingWindow`（line 7-8）
  - 删除 `CaptureOverlayPhase.scrolling`（line 20）
  - 删除属性 `scrollingSession`（line 44）、`scrollingPassThroughRect`（line 518）、`overlayView.scrollingPassThroughRect`（line 609）
  - 删除方法 `beginScrollingSession`、`finishFromScrolling`、`setScrollingPassThroughRect`
  - `handleSelectionReady` 中删除 `mode == .scrolling` 分支（line 166-169）
  - `handleCaptureRequest` 中删除 `.scrollingWindow` arm（line 335-339）及相关注释（line 401-402）
  - `finish` 中删除 `scrollingSession?.abandon(); scrollingSession = nil`（line 440-441）
  - `hitTest`、`handle(event:)`、`isSmartCapture`、`detect(preferWindow:)`、`dimAlpha`、chrome/handles guard、hint 文本（约 10 处分支）中删除 `.scrolling` / `phase == .scrolling` 分支

### 4. 入口与设置
- `MenuController.swift`：删除菜单项 `scrollingItem`（line 330-336）和方法 `startScreenshotScrolling`（line 715-718）。
- `ScreenshotCoordinator.swift`：`start(mode:)` 的 switch 中去掉 `.scrolling`（line 43）。
- `UI/ScreenshotSettingsView.swift`：删除默认模式 Picker 中的 `Text(.screenshotScrolling).tag(.scrolling)` 行（line 83）。

### 5. 本地化
- `Localization.swift`：删除 11 个 enum case（`screenshotScrolling`、`screenshotScrollingHint`、`...SelectHint`、`...Height`、`...EndHint`、`...LimitReached`、`...Moving`、`...Stitched`、`...TooFast`、`...Retry`、`...StreamingFailed`），以及 zh（line 520、549-558）和 en（line 803、832-841）对应字符串。

### 6. 设计令牌
- `UI/DesignTokens.swift`：删除 `ScreenshotChrome.scrollingMaxPixelHeight`（line 106，仅滚动截图使用）。

### 7. 文档
- `AGENTS.md`：更新「截图」功能描述去掉「半自动长截图」；删除 macOS 结构中对 `ScrollingCaptureSession.swift` 的条目。保留历史「对话记录」条目（属于工作日志，不篡改历史）。

### 不改动的内容
- `main.swift`、`ScreenshotCaptureService.swift`、`CaptureMagnifierView.swift`、`LogManager.swift`、`PreferencesManager.swift` 均无滚动截图专属代码，无需改动。
- SwiftUI/NSScrollView 等通用滚动容器（SettingsView/SearchView/HistoryPreview 等）与 PinPanel 的 scrollWheel 与本功能无关，保持不变。
- 保留对历史 `.scrolling` 默认值的安全降级（`PreferencesManager` 已有 `else { return .region }` 兜底）。

- 启动应用，确认菜单栏截图子菜单只剩「区域 / 窗口 / 全屏」，设置页默认模式 Picker 同步精简。
